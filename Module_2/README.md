# Module 2 — DataTable

## Overview

Module 2 moves from individual values to tabular data and figures. The four
exercises use pandas, Matplotlib, and Gapminder-derived CSV files in
`subject/`. Detailed explanations and reproducible transcripts are kept in
[`Docs/`](Docs/).

## Objectives

By the end of the module, we can load and validate CSV data, select DataFrame
indexes and columns, handle string year labels, inspect dtype inference and
missing values, choose wide or tidy data, and build Matplotlib figures with
axes, artists, legends, ticks, scales, and the `Agg` backend.
