# Exercice 01 — draw my country

## The problem

We select France from the life-expectancy table and draw its values from 1800
through 2100. The figure needs a title, an x-axis label, and a y-axis label.
The current script loads the indexed frame, prints it, plots the row, and
shows the figure. It has a known drift: `main()` runs at import time instead
of behind a `__main__` guard, and the unused pandas import is linted.

## The concept

The local loader uses `index_col=0`, so country names are row labels and years
are columns. We select the row by label:

```bash
.venv/bin/python -c "import pandas as pd; d=pd.read_csv('subject/life_expectancy_years.csv',index_col=0); f=d.loc['France']; print(d.shape, type(f).__name__, f.shape, f.index[0], f.index[-1], f.iloc[0], f.iloc[-1])"
# (195, 301) Series (301,) 1800 2100 34.0 92.3
```

`f` is a Series whose index carries the year labels and whose values carry the
measurements. Passing both `f.index` and `f.values` to `plot` preserves that
meaning. Passing only `f.values` is legal, but matplotlib then uses positions
0 through 300 as x coordinates. We can inspect the resulting path:

```bash
MPLBACKEND=Agg .venv/bin/python -c "import pandas as pd, matplotlib.pyplot as plt; f=pd.read_csv('subject/life_expectancy_years.csv',index_col=0).loc['France']; plt.plot(f.index,f.values); print(plt.gca().lines[0].get_path().vertices[[0,-1]].tolist())"
# [[0.0, 34.0], [300.0, 92.3]]
```

The strings are categorical x values. The visible labels say 1800 and 2100,
but the line is positioned at 0 and 300. Therefore `set_xticks(f.index[::40])`
selects readable labels at a stride; it does not change the data range. A
numeric limit such as `set_xlim(1800, 2050)` is the wrong operation on this
categorical coordinate system and can display an empty region. If we need
numeric year arithmetic, we convert the labels explicitly:
`f.index.astype(int)`.

The distinction between labels and legends matters here. `set_xlabel("Year")`
and `set_ylabel("Life expectancy")` identify the axes; they do not create a
legend. A legend requires an artist with `label=...` and a call to
`legend()`. The current line has neither, so the axes report no legend:

```bash
MPLBACKEND=Agg .venv/bin/python -c "import matplotlib.pyplot as plt; f,a=plt.subplots(); a.plot([1,2]); print(len(a.lines), a.get_legend())"
# 1 None
```

Matplotlib organizes this as `Figure` containing `Axes` containing artists.
The line is a `Line2D`; ticks, labels, and a possible legend are also managed
by the axes. We can check the current title and labels without opening a
window:

```bash
MPLBACKEND=Agg .venv/bin/python -c "import pandas as pd, matplotlib.pyplot as plt; f=pd.read_csv('subject/life_expectancy_years.csv',index_col=0).loc['France']; fig,ax=plt.subplots(); ax.plot(f.index,f.values); ax.set_title('France Life expectancy Projections'); ax.set_xlabel('Year'); ax.set_ylabel('Life expectancy'); print(ax.get_title(), ax.get_xlabel(), ax.get_ylabel(), len(ax.lines))"
# France Life expectancy Projections Year Life expectancy 1
```

Using `MPLBACKEND=Agg` makes this same artist inspection reliable on a machine
without a graphical display. It changes rendering, not the pandas selection or
the line's values, so it is suitable for automated checks of text, tick
locations, and artist counts.

```bash

```

The script exits 0, prints the `(195, 301)` frame, and may warn that the Agg
canvas is non-interactive. Expect the title `France Life expectancy
Projections`, axis labels `Year` and `Life expectancy`, and eight x tick labels
spaced by 40. The current lint baseline reports six findings, including the
module-level call and an unused import; the shared loader contributes the
remaining findings.

## Key take away

We select by country label, carry the year index into the plot, and use ticks
for readability rather than confusing them with filtering. String years create
a categorical axis, while numeric year operations require conversion. Axis
labels are not legend entries, and a headless Agg run lets us verify the
figure's artists and text without changing the Python file.
