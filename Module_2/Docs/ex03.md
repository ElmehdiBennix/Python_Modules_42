# Exercice 03 — draw my year

## The problem

We compare income per person with life expectancy for every country in 1900.
The result is a scatter plot: one point per country with both measurements.
The current program loads two indexed frames, selects the shared year label,
drops incomplete pairs, and draws the plot with Matplotlib. The x axis is
linear although income is highly skewed, and the loader prints each frame as a
side effect.

## The concept

The two files have different year coverage, so we inspect shape before joining:

```bash
.venv/bin/python -c "import pandas as pd; a=pd.read_csv('subject/income_per_person_gdppercapita_ppp_inflation_adjusted.csv',index_col=0); b=pd.read_csv('subject/life_expectancy_years.csv',index_col=0); print(a.shape, b.shape, a.index.equals(b.index), int(b['1900'].isna().sum()))"
# (195, 251) (195, 301) True 9
```

The country indexes happen to match, but label alignment is still safer than
pairing arrays by position. `year = "1900"` is essential because CSV headers
are strings; `data[1900]` raises `KeyError`. Income in this column is integer
data, while later columns may be `object` because suffixes occur. The current
income conversion handles `k` if it appears, and life values are converted
before the two Series are put into a new DataFrame. DataFrame construction
aligns Series on their index, so each country's values stay together even if
one Series is reordered.

We then call `dropna()`. That is a deliberate completeness rule: it removes a
country if either measurement is missing. The resulting point count can be
checked directly:

```bash
.venv/bin/python -c "import pandas as pd; a=pd.read_csv('subject/income_per_person_gdppercapita_ppp_inflation_adjusted.csv',index_col=0); b=pd.read_csv('subject/life_expectancy_years.csv',index_col=0); df=pd.DataFrame({'gdp':a['1900'],'life':b['1900']}).dropna(); print(df.shape, df.index[0], df['gdp'].min(), df['gdp'].max())"
# (186, 2) Afghanistan 360 9340
```

A scatter is appropriate because this is a cross-section, not a time path.
`scatter(x, y)` places independent markers; `plot(x, y)` would connect points
in their row order and imply a sequence. Matplotlib stores the 186 offsets in
one collection. The program supplies a graph label and calls `legend()`, while
the axis labels and title explain what the measurements mean.

Income spans a factor of about 26:

```bash
.venv/bin/python -c "import pandas as pd; d=pd.read_csv('subject/income_per_person_gdppercapita_ppp_inflation_adjusted.csv',index_col=0); x=d['1900']; print(x.min(), x.max(), round(x.max()/x.min()))"
# 360 9340 26
```

A log x scale can spread the low values without changing the observations.
`set_xscale("log")` changes the transform and tick placement; it does not
convert 360 into a different income. The current code leaves the scale linear,
which is a visible divergence from a log-scale reference. A positive
association in this scatter is not proof of causation: one year of country
averages cannot establish which factor causes the other.

## Key take away

We select a string year, align measurements by country labels, and state what
`dropna()` removes. We use Matplotlib scatter for independent country
observations, consider a log x scale for multiplicative income ranges, and
distinguish axis transforms from data changes. A positive cloud supports
association, not a causal conclusion.
