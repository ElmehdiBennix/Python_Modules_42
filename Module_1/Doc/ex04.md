## 3. What is a transpose?

A **transpose** reflects a matrix over its main diagonal: the element at row `i`
and column `j` moves to row `j` and column `i`.

```
Original            Transposed
[[1, 2, 3],         [[1, 4],
 [4, 5, 6]]   ->     [2, 5],
                    [3, 6]]
```

Formally: `T[i][j] = A[j][i]`. Applied to an image, it looks like the picture has
been **rotated by 90°** (and mirrored).

### 3.1 Why the crop must be a square

An `r × c` matrix transposes into a `c × r` matrix. A **400 × 400** square region
therefore transposes into another **400 × 400** region: the picture keeps its
proportions and the rotation is immediately visible.

A 400 × 200 rectangle would transpose into 200 × 400 — a stretched, distorted
picture.

### 3.2 The two coordinate systems

| | Rows (y) | Columns (x) |
|---|---|---|
| NumPy and the array | index `i` | index `j` |
| The transpose | `T[j][i]` | `T[i][j]` |

The crop `img_array[100:500, 450:850, 0:1]` is **400 rows tall × 400 columns wide**.

## 4. Concepts

### 4.1 Allocating the output array with `np.empty`

```python
rows, columns = arr.shape
out = np.empty((columns, rows), dtype=arr.dtype)
```

* `np.empty((r, c))` allocates an **uninitialised** array of that shape. It is
  fast, but the contents are arbitrary until every cell has been written.
* The shape is `(columns, rows)` — note the **swap**: the output has as many rows
  as the input had columns.
* `dtype=arr.dtype` preserves the pixel type (`uint8`), so the values stay within
  0–255 and the result can be displayed directly.
* `np.zeros((r, c))` is the safer alternative (zeros instead of arbitrary values).
  It makes no difference here because the loops fill **every** cell, but `np.empty`
  documents the intent "this will be filled completely".

### 4.2 The nested loop — transposing by hand

```python
for i in range(rows):
    for j in range(columns):
        out[j, i] = arr[i, j]
```

* The **outer** loop walks the rows of the **input** (`i` from 0 to `rows - 1`).
* The **inner** loop walks the columns of the **input** (`j` from 0 to `columns - 1`).
* The value `arr[i, j]` is written to `out[j, i]` — the indices are **swapped**.

That single swap *is* the transpose. The algorithm is O(n²) in Python and therefore
slow for large images, but for a 400 × 400 crop (160 000 assignments) it runs
instantly.

### 4.3 `range(n)` and `arr[i, j]`

* `range(rows)` produces the numbers `0, 1, 2, ..., rows - 1` — exactly the valid
  indices.
* `arr[i, j]` is the NumPy comma syntax for "row `i`, column `j`".
* `arr[i][j]` would also work but is slower, because it builds an intermediate
  array for the first index.

### 4.4 Dropping the channel axis safely

```python
cropped = img_array[y_start:y_end, x_start:x_end, 0:1]
arr = cropped[:, :, 0]
rows, columns = arr.shape
```

`cropped` has shape `(rows, cols, 1)`. The channel axis must be removed to obtain a
2D matrix, and there are two ways to do it:

| Expression | Result | Comment |
|---|---|---|
| `cropped.squeeze()` | `(rows, cols)` | also removes any axis of length 1 |
| `cropped[:, :, 0]` | `(rows, cols)` | removes **only** the channel axis |

> **Why the second form is preferable.** `squeeze()` removes *every* axis of length
> 1. If the crop happens to be one pixel wide or one pixel tall, the array
> collapses below two axes and the unpacking `rows, columns = arr.shape` raises
> `ValueError: not enough values to unpack (expected 2, got 0)` (or `got 1`).
> `cropped[:, :, 0]` always yields exactly two axes, whatever the crop dimensions,
> and is therefore the robust choice.
>
> `np.squeeze(cropped, axis=2)` is an equally explicit alternative.

### 4.5 Verifying the transpose

NumPy offers `arr.T` and `np.transpose(arr)`, which the subject forbids in the
implementation. They remain useful as a **test oracle**: a hand-written transpose
must produce the same result as `arr.T`.

```python
np.array_equal(out, arr.T)   # -> True
```

The equality can be checked on the real crop as well as on an asymmetric toy matrix
such as `np.arange(6).reshape(2, 3)`, where a wrong index order is immediately
visible.

### 4.6 `np.array([])` as the error return value

```python
except (TypeError, ValueError, IndexError) as error:
    print(f"Error in ft_rotate: {error}")
    return np.array([])
```

* `np.array([])` is an empty array — `.shape` is `(0,)` and `.size` is `0`.
* It has the **same type** as the normal return value (a NumPy array), so the
  caller never receives an unexpected `None`.
* The caller then checks `if cropped.size > 0:` before displaying the result.

## 5. Implementation walkthrough

`ex04/rotate.py`:

```python
cropped = img_array[y_start:y_end, x_start:x_end, 0:1]
# Drop only the channel axis: squeeze() would also collapse a crop
# whose width or height is 1, leaving an array with less than 2 axes.
arr = cropped[:, :, 0]

rows, columns = arr.shape
out = np.empty((columns, rows), dtype=arr.dtype)

for i in range(rows):
    for j in range(columns):
        out[j, i] = arr[i, j]

print(f"New shape after Transpose: {out.shape}")
return out
```

Step by step:

1. **Crop** a square region, keeping a single channel → `(400, 400, 1)`.
2. **Drop the channel axis** → `(400, 400)`.
3. **Allocate** the output with the swapped shape → `(400, 400)`.
4. **Fill** it using the swapped indices → the transpose, performed by hand.
5. **Print** the new shape and return the array.

The whole computation is O(400 × 400) = 160 000 assignments — a fraction of a
second in Python, and it demonstrates exactly the algorithm the subject requires.

## 8. Key takeaways

1. **A transpose swaps the row and column indices**: `T[j][i] = A[i][j]`.
2. **Crop a square** so the transposed picture keeps its proportions.
3. **`np.empty((columns, rows))`** allocates the output with the swapped shape.
4. **Nested `for` loops over `range()`** are the standard way to walk a 2D array.
5. **Remove only the axis that is meant to disappear.** `squeeze()` removes every
   axis of length 1 and can leave an array with fewer than two dimensions;
   `arr[:, :, 0]` is explicit and always safe.
6. **`np.array_equal(out, arr.T)`** is the right way to prove a hand-written
   transpose is correct — as a test, not as the implementation.
7. **`np.empty` versus `np.zeros`**: `empty` is faster but uninitialised; use
   `zeros` when some cells might remain unwritten.
