# Module 1 — Array

## Overview

Module 1 introduces NumPy arrays through BMI data, two-dimensional arrays,
images, slicing, transposition, and pixel filters. Detailed explanations and
reproducible transcripts are kept in [`Docs/`](Docs/).

## Objectives

By the end of the module, we can predict array shape, dtype, strides, views,
and copies; use boolean masks and broadcasting; convert image channels with
Pillow; and create and inspect Matplotlib figures. The exercise documents
explain the operation specific to each exercise.
