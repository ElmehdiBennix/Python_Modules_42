# Module 3 — Object-oriented programming

## Overview

Module 3 introduces classes and protocols through a Game of Thrones hierarchy,
multiple inheritance, and vector arithmetic. Detailed explanations and
reproducible transcripts are kept in [`Docs/`](Docs/).

## Objectives

By the end of the module, we can design class and instance namespaces, use
abstract base classes, trace method resolution order and `super()`, implement
descriptors and properties, and apply dunder protocols, class methods, static
methods, and operator dispatch.
