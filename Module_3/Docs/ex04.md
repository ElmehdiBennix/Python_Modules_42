# Exercice 04 — Dot product and vector operations

## The problem

Reuse the `calculator` idea for two vectors of identical size and provide three
operations: a dot product, an element-wise addition and an element-wise
subtraction. Each prints its result and returns `None`. The constraint is the
call site: the tester writes `calculator.dotproduct(a, b)` and never constructs
a `calculator`, so all three must work on the class itself. No error handling is
required.

## The concept

A decorator is a callable that receives a function and returns something to
store in its place. `@staticmethod` stores a `staticmethod` object in the class
namespace: `calculator.__dict__['dotproduct']` prints
`<staticmethod(<function calculator.dotproduct at ...>)>`. That object is a
descriptor whose `__get__` returns the underlying function unchanged, ignoring
both the instance and the class. Accessing `calculator.dotproduct` therefore
yields a plain function with no `__self__`, and the call supplies exactly the
two declared vectors.

An ordinary function is also a descriptor, but it binds differently: through an
instance it receives the instance as the first argument, while through the class
in Python 3 it binds nothing. A method written as
`def dotproduct(self, V1, V2)` and called as `calculator.dotproduct(a, b)`
fails with `TypeError: ... missing 1 required positional argument: 'b'`,
because the call passes `a` into the `self` slot. One written with the subject's
signature, no `self`, works through the class but fails through an instance:
`calculator().dotproduct(a, b)` raises `TypeError` because three arguments
arrive for two parameters. `@staticmethod` removes the difference, so both call
sites pass exactly the two vectors.

`@classmethod` is the wrong tool. Its descriptor binds `cls` as an extra first
argument, so a body expecting only two vectors receives three arguments and
raises `TypeError`. Adding `cls` would make it run, but the class plays no part
in the arithmetic; the parameter is noise. `classmethod` is for constructors
that need the class; `staticmethod` is for functions that need neither the class
nor the instance but belong in the class's namespace. A module-level function
would also work at this call site; the decorator keeps the name attached to
`calculator`.

The dot product multiplies matching positions and sums them:
`5*2 + 10*4 + 2*3 = 56`. Because the inputs are integers, the accumulator stays
an `int` and prints as `Dot product is: 56`. `add_vec` and
`sous_vec` cast each pair with `float(...)` before combining, so integer inputs
produce `[7.0, 14.0, 5.0]` and `[3.0, 6.0, -1.0]`. `zip` walks both lists in
step and stops at the shorter one: `list(zip([1, 2, 3], [4, 5]))` is
`[(1, 4), (2, 5)]`. The subject guarantees identical sizes, so the truncation is
accepted rather than checked.

The printed text follows the subject. The subject specifies
`Dot product is: 56`, `Add Vector is : [7.0, 14.0, 5.0]` and
`Sous Vector is: [3.0, 6.0, -1.0]`, including the space before the colon in the
second label. The class and its methods have docstrings, as required by the
module rules.

The tester is supplied at module level with no `if __name__ == "__main__"`
guard. Importing it runs all three operations before the import returns:
`python -c "import tester; print('after import')"` prints `56`, the two lists,
then `after import`. That is the subject's layout, not a property of
`ft_calculator`, but it means the tester cannot be imported without producing
output.

## Key take away

The decorator decides how a method is looked up, so it decides the signature the
caller must satisfy. `@staticmethod` removes both instance and class from the
call, the right choice for a pure function in a namespace. `@classmethod` suits
constructors and factories that need the class, and a plain method suits
behaviour that depends on the instance. Element type leaks into printed output,
so an `int` sum and a `float` list can differ even when the arithmetic agrees.
Read the exact output specification character by character, including where
spaces and labels sit.
