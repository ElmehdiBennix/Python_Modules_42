# Python Modules 42

This repository is a guided progression through the Python modules of the
42 curriculum. The reading path is deliberate: this page introduces the
modules, each module README summarizes its subject and links every exercise,
and each exercise document teaches the mechanism, objective, current behavior,
and validation command.

## Modules

- [Module 0 — Python basics](Module_0/README.md): containers, validation,
  command-line input, generators, and packaging.
- [Module 1 — Array](Module_1/README.md): NumPy arrays, images, slicing,
  transposition, and pixel operations.
- [Module 2 — DataTable](Module_2/README.md): pandas DataFrames, CSV data,
  reshaping, and Matplotlib visualisation.
- [Module 3 — Object-oriented programming](Module_3/README.md): abstract
  classes, inheritance, method resolution, properties, and operator methods.
- [Module 4 — Data-oriented design](Module_4/README.md): keyword dispatch,
  closures, decorator factories, and dataclasses.

## Working through the repository

The Markdown files are the project guide. Together they cover the subject
requirements, the language and library concepts, the implementation's actual
behavior, expected outputs, known subject-versus-code differences, lint
status, and acceptance criteria for unfinished stubs. Running the checks is
part of reading the material: outputs, exceptions, lint findings, and data
shapes are evidence for the explanations rather than claims made in isolation.
