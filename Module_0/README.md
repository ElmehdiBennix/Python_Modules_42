# Module 0 — Python basics

## Overview

Module 0 introduces the Python fundamentals used throughout the 42 curriculum.
The subject progresses from containers and values to command-line validation,
generators, and package creation. Detailed explanations and reproducible
transcripts are kept in [`Docs/`](Docs/).

## Objectives

By the end of the module, we can distinguish mutable and immutable objects,
use identity and equality deliberately, classify exact types, validate
`sys.argv` input, apply modulo arithmetic, build comprehensions and lambda
expressions, write lazy generators, preserve docstrings, and inspect PEP 621
package metadata.
